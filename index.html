Mis Habilidades Tecnológicas

Front-End

El front-end se encarga de todo lo que el usuario ve e interactúa directamente en un sitio o aplicación web (la interfaz visual y la experiencia de usuario).

Back-End

El back-end se encarga de toda la lógica interna, la seguridad y la gestión de datos que ocurren en el servidor ("detrás de escena"), haciendo posible que la aplicación funcione correctamente.

Full-Stack

El full stack se encarga de cubrir tanto el front-end (la interfaz de usuario) como el back-end (la lógica del servidor y datos), permitiéndole desarrollar una aplicación web completa de principio a fin.
